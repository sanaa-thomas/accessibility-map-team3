# **UMBC Accessibility Campus Map**

A student‑built, accessibility‑first interactive campus map designed to help students, staff, and visitors navigate UMBC with clarity and confidence. This project was developed as part of a semester‑long SCRUM‑based software engineering course, where I served as SCRUM Master and coordinated the team’s workflow, documentation, and deliverables.


**Demo:** https://drive.google.com/file/d/1tab2jwXNErgLJNyPSaGLsQhofF3G2iFI/view?usp=sharing

## **Overview**

This project provides an interactive map of the UMBC campus highlighting key accessibility features, including:

- Accessible entrances

- Ramps and elevators

- Sidewalks and pathways

- Parking lots and designated accessible parking

- Building information and navigation cues

The goal was to create a tool that improves campus mobility for individuals with disabilities and supports UMBC’s commitment to inclusive design.

## **Project Goals**

- Build a user‑friendly, accessibility‑centered campus navigation tool

- Provide clear visual markers for accessibility features

- Ensure the map is intuitive for new students, visitors, and staff

- Practice real‑world Agile/SCRUM development workflows

- Deliver a functional MVP within a fixed academic timeline
